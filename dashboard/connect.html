GitHub App

推荐最终权限

  • Metadata（仓库基本信息）：只读
  • Contents（仓库文件）：读写
  • Pull requests（合并请求）：读写
  • Actions（构建任务）：读写
  • Administration / Workflows：不需要授权

安全说明

安全边界

  • GitHub 登录使用 GitHub App + PKCE，并校验登录请求来自当前浏览器。
  • GitHub 访问凭据只在服务端加密保存，不下发到浏览器。
  • 浏览器只保存 HttpOnly 登录会话 Cookie，前端脚本无法直接读取。
  • 公开页面不调用需要授权的 GitHub API，也不保存 GitHub 凭据。
  • 所有写操作还会校验请求来源和 CSRF 防护信息。

启用顺序

模板实例启用顺序

  1. 创建 Cloudflare D1 数据库，并配置部署所需的 GitHub Actions 密钥和变量。
  2. 运行 Deploy V2 Control Plane，先完成首次空配置部署。
  3. 按上面的权限创建 GitHub App，再把 App 密钥同步到部署环境。
  4. 确认登录、仓库读取和一次实际操作都正常后，再在自己的仓库启用 dashboard/data/control-plane.json。

公共模板的 main 会刻意保持连接配置关闭，避免模板实例误连到维护者自己的 Worker。

V2 管理中心 本页面不持有 GitHub 凭据。
