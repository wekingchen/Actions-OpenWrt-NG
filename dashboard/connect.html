Capabilities

当前已完成能力

  • Profile：读取、在线编辑或直接新建标准 Profile，并在写入前预览结果。
  • 安全保存：新建与编辑都固定走原子 commit → 独立分支 → Pull Request，不直接修改默认分支。
  • Builder：固定调度 OpenWrt NG Builder，自动跟踪 Run / Job 状态。
  • 产物：查看 Artifact、Workflow Summary 与匹配的 Release 入口。

GitHub App

推荐最终权限

  • Metadata：Read-only
  • Contents：Read and write
  • Pull requests：Read and write
  • Actions：Read and write
  • Administration / Workflows：不需要

Security

安全边界

  • GitHub App Web Flow + PKCE，OAuth state 绑定发起浏览器。
  • GitHub access / refresh token 仅在服务端加密保存。
  • 浏览器只持有 HttpOnly Session Cookie。
  • 公开 Pages 不调用带权限的 GitHub API，也不保存 Token。
  • 写操作额外校验同源 Origin 与 CSRF 请求头。

Template Setup

模板实例启用顺序

  1. 创建 D1，并配置 Cloudflare Actions Secret / Variable。
  2. 运行 Deploy V2 Control Plane 完成 bootstrap。
  3. 按最终权限创建 GitHub App，再同步 App Secret。
  4. 完成真实登录与仓库验证后，在自己的仓库启用 dashboard/data/control-plane.json。

公共模板的 main 会刻意保持连接配置关闭，避免模板实例误连到维护者自己的 Worker。

V2 Control Plane 本页面不持有 GitHub 凭据。
